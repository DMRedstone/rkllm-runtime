# restructure_devlog 说明

## 定位

重组《开发记录》：按时间顺序 + 开发版本把章节重新分卷分章，取消混乱分章。

## 做法

按**行号切片** → 建立「旧块 → 新卷/章」映射 → 重新拼接。不改动块内任何文字，
只新增卷/章标题行，因此内容零丢失；脚本末尾自动做零丢失校验
（源文件每个非空行都必须出现在输出中）。

## 用法

```bash
python restructure_devlog.py     # 原地重写 文档/开发记录.md
```

## 前置与注意

- 执行前务必备份原文件（脚本假设已由调用方备份）；
- `BLOCKS` 字典是唯一的映射表，改结构只改这一处；
- 若源文件行号已变（例如又追加了内容），需先更新 `BLOCKS` 再运行；
- 与 `renumber_devlog.py`、`append_devlog_sections.py` 配套使用，三者
  按此顺序执行。

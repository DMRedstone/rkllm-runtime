# f3_scenarios 说明

## 定位

F3 七类辅助任务真机验收：每类 5 条，共 35 条，板端本地跑（`127.0.0.1`），
输出可供人工判定。

七类：摘要 / 改写 / 抽取 / 分类 / 翻译 / 短问答 / 批量。

## 判据（设计 G2）

- 单条 < 60 s 返回；
- 输出与任务类型匹配；
- 无乱码、无 `</think>` 等标签残留。

## 输出

- 终端实时进度：序号、类型、耗时、字数、输出前 40 字；
- `/tmp/f3_result.json`：每条完整记录 + 按类型的汇总
  （通过数、平均/最慢耗时、是否全部 < 60 s）。

## 用法

```bash
python f3_scenarios.py        # 需板端服务在 127.0.0.1:8080 就绪
```

## 注意

脚本内置 `CASES` 列表，改用例直接编辑该列表；结果文件写在 `/tmp`，
重启即失，需要留痕请另行复制。

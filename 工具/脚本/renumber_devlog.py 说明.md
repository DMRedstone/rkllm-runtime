# renumber_devlog 说明

## 定位

统一《开发记录》章编号为「卷.章」形式，消除缺号与重号。

在 `restructure_devlog.py` 输出的基础上执行。

## 做法

`RENUMBER` 字典给出「行号 → (新编号, 是否由 `###` 提升为 `##`)」。脚本：
剥掉旧前缀（中文数字章号、裸日期章号、「附录：」）→ 写入 `## 卷.章 标题`。

章节**内部**既有的 `### 11.1` 式小节编号保持不变，以保留与 git 提交历史的
对应关系。

## 用法

```bash
python renumber_devlog.py        # 原地重写 文档/开发记录.md
```

## 前置与注意

- 必须在 `restructure_devlog.py` 之后运行（依赖其产生的行号）；
- 若目标行不是章节标题，或预期为 `###` 而实际不是，脚本报错退出而不是
  静默跳过；
- 结尾自动校验：所有 `##` 章均为「卷.章」或「附录 X」形式。

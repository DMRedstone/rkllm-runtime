# append_devlog_sections 说明

## 定位

向重组后的《开发记录》追加新的章节或附录，避免直接手改长文档。

当前内置三段内容：

1. §7.13 真机安装与缓存链路闭环；
2. 附录 B 《十五版本以来改造审计报告》结论存档；
3. 附录 C 待办事项核对清单。

## 做法

- §7.13 插在 `# 附录` 分隔标题之前（自动回退到该标题前的 `---` 分隔线，
  保持格式整齐）；
- 附录 B / C 追加到文末。

## 用法

```bash
python append_devlog_sections.py     # 原地追加
```

## 注意

- **重复执行会重复插入**。若已执行过，先 `git checkout` 还原再改内容；
- 新增章节时编辑脚本顶部的 `SECTION_713` / `APPENDIX_B` / `APPENDIX_C`
  三个字符串常量；
- 执行后建议 `grep -n "^## " 文档/开发记录.md` 核对章节顺序。

### 一、开源惯例偏离项（按开源做法修）

- [ ] **O-1 prompt cache 字节级前缀 → token 级匹配**
      现状：`promptcache.py` 用 `prompt.startswith(meta)` 字节级比较。
      开源对照：llama.cpp `server_tokens::get_common_prefix()` 逐 token
      （uint32 id）线性比较 + `--slot-prompt-similarity` 阈值门控；
      vLLM 用链式块哈希 + LRU + 引用计数。
      方案：本仓库无 tokenizer，先用「字节级 LCP + 相似度阈值」对齐 llama.cpp
      的 `slot_prompt_similarity` 语义；`--cache-ram` 式纯 RAM 缓存已由
      tmpfs 实现，保持。若后续引入 tokenizer 再升到 token 级。
- [ ] **O-2 取消链路实现 vLLM 两段式契约**
      现状：`watch_disconnect` 只 abort 一次、不回传主循环。
      开源对照：vLLM「框架取消 generator → `CancelledError` → `abort()`
      归还 KV 块 → re-raise」；llama.cpp `SERVER_TASK_TYPE_CANCEL` 插队 +
      三队列清理。
      方案：与「流式三套合并」合并实施（见 F-1）。
- [ ] **O-3 MCP 连接器实现 fd 隔离**
      现状：`stdio.py` 直接读写 fd 0/1，`print()` 或子进程输出可污染
      JSON-RPC 线。
      开源对照：Python SDK `stdio_server()` 的 `_claim_fd`——服务期把 fd 0
      重定向到空设备、fd 1 到 stderr，协议走 dup 出的私有描述符。
      方案：照搬该机制。

### 四、流式基础设施合并（F-1，含 O-2）

- [ ] 现状三套并存且全半成品：① `queue.run(cancelled=)` 取消回调——两个
      调用方都不传，死参数；② `watch_disconnect` 一次性 abort——不回传主
      循环；③ pump `Full` break（openai）/ 无保护（responses）——已漂移。
      方案：提取统一 `CancelToken`/`StreamContext`（取消、断连、背压、心跳
      四事一处），实现 vLLM 式「框架取消 → abort 归还 KV 块 → re-raise」
      两段式契约；同时把 openai/responses 重复的约 80 行 SSE 骨架抽为
      共享件，`_STREAM_DONE` 单份定义。

本文件夹是 rkllm-runtime Debian 包 的构建输入。它只放"打包需要的东西"，不放工具脚本（工具在「工具/编译工具链」），也不放产物（产物在「交付」）。

## 一、packaging/

打包脚手架，被 `工具/编译工具链/make_deb.py` 直接读取（脚本内固定按 `packaging/` 这个目录名加载）。

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `control.in` | 模板 | Debian 包元数据（包名/版本/依赖/描述），构建时渲染 |
| `postinst` / `prerm` / `postrm` | 维护脚本 | 安装后跑 `ldconfig`；卸载停服务并清理 conffile（全包唯一的删除动作） |
| `changelog.Debian.in` | 模板 | Debian 变更日志，构建时 gzip -9、mtime 归零 |
| `README.Debian.in` | 模板 | 装到 `/usr/share/doc/rkllm-runtime/README.Debian` |
| `copyright.head` | 模板 | 与上游 `LICENSE` 拼接成 Debian copyright |
| `rkllm.pc.in` / `rkllm-config.cmake.in` / `rkllm-config-version.cmake.in` | 模板 | pkg-config 与 CMake `find_package(rkllm)` 的查找文件 |
| `launcher/rkllm` | 源码 | 装为 `/usr/bin/rkllm`：统一入口，挂 `sys.path` 后调 `rkllm.cli`（1.3.1-16 起旧单文件 `cli/rkllm.py` 已删除） |
| `src/rkllm/` | 源码 | 新栈模块树（FastAPI 服务端 / worker / agent / mcp），装到 `/usr/lib/rkllm/current/rkllm` |
| `default/rkllm-server` | 模板 | 装为 `/etc/default/rkllm-server`，声明为 dpkg conffile，升级不改、卸载删除 |
| `man/rkllm.1`、`man/zh_CN/rkllm.1` | 手册 | 中英双语 man，构建时 gzip |
| `systemd/rkllm-server.service` | 单元 | 装为 `/usr/lib/systemd/system/rkllm-server.service`，不 enable 不 start |
| `overrides/` | 改写件 | 对上游示例的 CMakeLists / build-linux.sh 的替代版本，另含 `text-patches.json` 行内补丁。所有对上游文件的改动都集中在这里，便于追溯 |

这些名字是 dpkg / CMake / systemd 的约定名，也是构建脚本按路径读取的接口名，不要改名。

## 二、rknn-llm-release-v1.3.1.tar.gz

上游 RKLLM SDK 发行包（版本 1.3.1），是构建的源料。

- 原始发行包 160 MiB。此前提供过精简归档（27.1 MiB，483 个条目）以适配资料库单文件上限；**现该文件不入库**，需要时按下面的剔除清单自行裁剪。

- 精简只做删除，不改内容、不改目录结构、不改文件名与权限，包内顶层仍为 `rknn-llm-release-v1.3.1/`。

- 剔除清单（均为构建 arm64 Debian 包所不需要的部分）：

| 剔除内容 | 原因 |
| --- | --- |
| `rknpu-driver/` | NPU 内核驱动随板端系统镜像预置，包不含也不编译 DKMS |
| `rkllm-toolkit/` | x86_64 主机上的模型转换工具（wheel），不进 arm64 包 |
| `rkllm-runtime/Android/` | 非目标平台 |
| `examples/**/librknnrt/Android/` | 非目标平台 |
| `examples/**/librknnrt/Linux/rknn_server/` | RKNN 代理服务，不属于 RKLLM 运行库 |
| `examples/**/opencv/OpenCV-android-sdk/` | Android OpenCV 静态库，与 arm64 构建无关 |
| `examples/**/opencv/opencv-linux-armhf/` | 非目标架构（只交付 arm64） |

- 保留内容：`rkllm-runtime/Linux/`（`aarch64` 运行库与 `rkllm.h` 头文件）、`examples/`（示例源码与 arm64 三方件）、`doc/`（中英 SDK 手册）、`res/`、`scripts/`、`README.md`、`CHANGELOG.md`、`benchmark.md`、`LICENSE`。

## 三、怎么用

```bash
# 从资料库下载上面的 tar.gz，然后构建（arm64 为唯一交付架构）
export RKLLM_RELEASE_TARBALL=/path/to/rknn-llm-release-v1.3.1.tar.gz
python tools/make_deb.py --arch arm64 --emit-tree
python tools/verify_deb.py
python tools/crosscheck_deb.py
```

不设环境变量时也可以显式传 `--source <路径>`。若两者都不给，脚本会退回开发机上的默认路径（仅在本机有效）。
